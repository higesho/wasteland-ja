# ウェイストランド 日本語化パッチ

Steam 版「Wasteland 1 - The Original Classic」を日本語で遊べるようにする、非公式のファンメイド日本語化パッチです。
開発元・販売元とは関係ありません。

- サイト（紹介・入れ方）: https://higesho.github.io/wasteland-ja/
- ダウンロード: [リリース](https://github.com/higesho/wasteland-ja/releases/latest) の `Wasteland_JP.zip`
- バーズテイル三部作の日本語化: https://higesho.github.io/bardstale-ja/
- ウルティマ シリーズの日本語化: https://higesho.github.io/ultima-ja/
- ウィザードリィ シリーズの日本語化: https://higesho.github.io/wiz-ja/

## 入れ方

1. `Wasteland_JP.zip` の中の `winmm.dll` を、ゲームのフォルダ（`wasteland.exe` があるフォルダ）に置きます。
2. いつもどおり Steam から起動します。

外すときは、`winmm.dll` を消せば英語版に戻ります。
ゲームのファイルは書き換えません。配布物には原作のプログラムやデータは入っていません。
